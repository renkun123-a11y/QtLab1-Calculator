# 开发与测试记录（实验 1：带键盘事件的计算器）

本文件按开发顺序记录每一步做了什么、测了什么、发现了什么问题以及如何修改，
报告中的"测试输入 → 原程序现象 → 原因分析 → 修改方法 → 修改后结果"即取自这里。

开发环境：Qt 6.7.2 (MinGW 64bit) / GCC 13.1.0 / qmake + mingw32-make / Windows 11。

---

## 阶段 1　工程骨架（commit 1）

- qmake 工程 + `main.cpp` 最小窗口，确认 MinGW 工具链可用。
- 记录一个环境问题：qmake 的 CRT 会把命令行中的中文路径解析成 `???`，
  因此 `build.bat` 中一律使用**相对路径**调用 qmake；构建目录也建议放在纯英文路径下。

## 阶段 2　界面（commit 2）

- `mainwindow.ui` 用 QVBoxLayout（显示区 + 键盘区）+ QGridLayout（6 行 × 4 列）完成布局。
- 24 个按键统一用动态属性 `calcKey`（含义）与 `buttonRole`（样式分类）标注。
- 观察：`⌫`(U+232B) 在"微软雅黑"和"Segoe UI Symbol"里都没有字形，按钮显示为方框，
  改用 `←`(U+2190) 后正常显示。

## 阶段 3　四则运算核心（commit 3）

- 新增 `CalculatorEngine`（纯逻辑，不依赖控件）与 `Calc::Key` 按键令牌，
  24 个按键按 `calcKey` 批量连接到统一入口 `MainWindow::dispatchKey()`。

手工点击测试（`[ ]` 内为主显示区实际显示值）：

| 序号 | 测试输入 | 期望 | 实际 | 结论 |
| --- | --- | --- | --- | --- |
| 1 | `1` `+` `2` `=` | 3 | `3` | 通过 |
| 2 | `2` `+` `3` `=` 然后 `4` | 4（开始新的计算） | `4` | 通过 |
| 3 | `8` `÷` `0` `=` | 提示除数为 0 | `inf` | **缺陷 A** |
| 4 | `1` `+` `2` `+` `3` `=` | 6 | `5` | **缺陷 B** |
| 5 | `1` `.` `5` `+` `2` `=` | 3.5 | `17` | **缺陷 C** |

缺陷分析：

- **A（除数为 0）**：`compute()` 直接做 `lhs / rhs`，IEEE 754 下 `8.0 / 0.0` 得到 `inf`，
  再被 `formatNumber()` 用 `'g'` 格式输出成 `inf`。程序没有任何错误状态，用户也无法恢复。
- **B（连续运算）**：`inputOperator()` 无条件把当前显示值当作左操作数，
  输入 `1 + 2 +` 时用 `2` 覆盖了左操作数 `1`，把"待执行运算"丢掉了，
  于是 `3` 变成 `2 + 3` 的右操作数。
- **C（小数）**：本阶段尚未实现小数点按键，`.` 被忽略，`1.5` 实际输入成了 `15`。

以上三条在阶段 4 / 阶段 5 修复。

## 阶段 4　小数输入与编辑操作（commit 4）

- 新增小数点、退格、CE（清除当前输入）、C（全部清除）处理，
  并把"运行过程中表达式栏该显示什么"抽成 `currentExpressionText()`，避免重复拼接字符串。

点击测试结果：

| 序号 | 测试输入 | 期望 | 实际 | 结论 |
| --- | --- | --- | --- | --- |
| 6 | `1` `.` `5` `+` `2` `=` | 3.5 | `3.5` | 缺陷 C 已修复 |
| 7 | `1` `.` `.` `.` `5` | 1.5（重复小数点被忽略） | `1.5` | 通过 |
| 8 | `.` `5` | 0.5（自动补前导 0） | `0.5` | 通过 |
| 9 | `1` `2` `3` `←` | 12 | `12` | 通过 |
| 10 | `1` `2` `+` `3` `4` `CE` | 显示 0，表达式仍为 `12 +` | `0` | 通过 |
| 11 | `1` `+` `×` `2` `=` | 2（连续运算符以最后一次为准） | `2` | 通过 |

避免重复小数点的关键写法：小数点只在"当前操作数文本里还没有 `.`"时才追加。

```cpp
void CalculatorEngine::inputDot()
{
    if (m_startNewEntry) {
        m_entry = QStringLiteral("0.");   // 直接按小数点，自动补前导 0
        m_startNewEntry = false;
    } else if (m_entry.contains(QLatin1Char('.'))) {
        return;                           // 同一个操作数只允许一个小数点，重复输入直接忽略
    } else {
        m_entry += QLatin1Char('.');
    }
    m_expression = currentExpressionText();
}
```

暂时遗留：缺陷 A（除数为 0 显示 `inf`）与缺陷 B（连续运算只算了最后一步）。
